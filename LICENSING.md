# Repository Licensing Files

This directory contains the public-facing licensing documents intended to be committed with CLEAR.

## Included

- `LICENSE.md` - explains the dual-license model, commercial-use boundary, noncommercial liability position, and commercial licensing contact.
- `LICENSE-POLYFORM-NONCOMMERCIAL-1.0.0.md` - the unmodified PolyForm Noncommercial License 1.0.0 used for qualifying noncommercial use.
- `NOTICE.txt` - required copyright notice.
- `CLA.md` - submission-based contributor license agreement.
- `CONTRIBUTING.md` - makes CLA acceptance conspicuous before contribution.
- `.github/PULL_REQUEST_TEMPLATE.md` - repeats the CLA notice in pull requests.
- `TRADEMARK-POLICY.md` - separates software rights from rights in the project name, logo, and branding.

## Submission-based CLA

The Project does not require a separately signed CLA, contributor-registration database, CLA bot, or standalone electronic-signature record.

A contributor accepts the CLA by intentionally submitting a Contribution through a designated Project contribution channel. Preserve ordinary Git and hosting-platform history, and commit CLA changes normally rather than rewriting CLA history, so the CLA version applicable to a Contribution can later be determined.

Do not treat code merely found in a fork, vendored dependency, automated update, cherry-pick, or third-party import as though the original rights holder accepted the CLA. The submitter can grant only rights the submitter actually owns or controls.

## Deliberately not included

Commercial contracts are private deal documents and are not needed in the public repository. In particular, the repository does not include the commercial master license agreement, order forms, negotiated liability/risk schedules, founder IP-assignment documents, or internal legal deployment checklists.

A prospective commercial user should contact:

**florent@chandelier.io**

for the applicable commercial agreement and pricing.

## File integrity

`LICENSE-POLYFORM-NONCOMMERCIAL-1.0.0.md` is included unmodified. The project
accepts external contributions under `CLA.md`; the contribution guide and
pull-request template make its submission-based acceptance mechanism
conspicuous.

This licensing model is source-available rather than OSI-approved open source because commercial use can require a separate paid license.
